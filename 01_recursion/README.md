  ## Recursion

  ### What is recursion?

  Function calls itself to solve smaller version of the same problem.

  ### Two parts of Recursion

  #### Base Case
  This is the stop condition. When to stop calling the function.

  #### Recursive Case
  The part where function calls itself.

  ### Common mistakes
  * Missing Base case. This will lead to stack overflow.
  * Not simplifying the input. In this case it will not reaches the base case.
  * Too deep recursion.
  * Keeping in mind the time complexity. O(n)

  ### When to use this?

  * Problem can be broken into sub problem.
  * Trees and Graphs.
  * Backtracking, DP, Divide and Conquer.
